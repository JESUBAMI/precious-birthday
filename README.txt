PRECIOUS OS - BIRTHDAY WEBSITES (desktop style)
==============================================
Open index.html for the Precious birthday page.
Open taiwo-kehinde.html for the Oriji twins birthday page.
The separate taiwo-kehinde/ folder is a self-contained copy for its own Vercel project.

Keep the HTML pages, style.css, script.js, data files, images/ and videos/ together.
To add the twins' pictures, place them in images/ and add their filenames and
captions to the PHOTOS array in twins-data.js.

Test on your computer: unzip, then double-click the HTML page you want.
Put it online: upload everything inside this folder to your GitHub repository
(Add file > Upload files > Commit changes). Vercel redeploys automatically.
The twins' wish button sends to the WhatsApp number set in twins-data.js.
The Precious wish button's number remains set in script.js as before.
For a separate twins Vercel link, import this repository as a new Vercel project
and choose taiwo-kehinde as its Root Directory. See taiwo-kehinde/README.txt.
