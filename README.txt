PRECIOUS BIRTHDAY WEBSITE (full version)
========================================
Files: index.html (open this), style.css, script.js, images/, videos/
Keep them together in one folder.

Test on your computer: unzip, then double-click index.html.

To put it online with Vercel (via GitHub):
  1. Open your GitHub repository for the site.
  2. Click Add file > Upload files, drag in everything from inside this folder, then Commit changes.
  3. Vercel redeploys automatically in about a minute.

The wish button sends messages to Precious on WhatsApp.
To change the number: open script.js, find  var waNum='...'  and put the new number there
(international format, no plus sign or spaces).
